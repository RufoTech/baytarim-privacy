Baytarım — Məxfilik Siyasəti

Son yenilənmə: 27 oktyabr 2026 · Tətbiq: Baytarım (com.rainnovation.baytarim)
AZ EN RU

1. Kimik

Baytarım Bakı və ətrafında baytar klinikalarını tapmaq, heyvan profili saxlamaq, rezervasiya və təcili (SOS) yardım üçün nəzərdə tutulmuş mobil tətbiqdir. Operator: RA Innovations / Rufat Alakbarli. Əlaqə: alekberovrufa@gmail.com.

2. Hansı məlumatları toplayırıq

  • Hesab: e-poçt/parol, Google hesabı ilə giriş və ya telefon (SMS) təsdiqi; ad və profil şəkli.
  • Heyvan məlumatları: ad, növ, cins, yaş və sizin yüklədiyiniz foto.
  • Məkan: yaxın klinikaları göstərmək üçün cihazın təxmini/dəqiq yeri (icazə verdikdə).
  • Rezervasiyalar və rəylər: klinikaya yazıldığınız vaxtlar, ziyarət tarixçəsi və rəylər.
  • Cihaz və bildirişlər: push bildiriş tokeni, tətbiq istifadəsi üçün əsas texniki loglar.
  • Favorilər və tənzimləmələr: seçdiyiniz klinikalar, SOS düyməsi/widget tənzimləmələri.

3. Necə istifadə edirik

  • Xəritədə klinikaları göstərmək və naviqasiya linkləri vermək
  • Hesab, heyvan profili və rezervasiyaları idarə etmək
  • Bildirişlər (məs. rezervasiya yeniləmələri) göndərmək
  • Təcili yardım (SOS) və home-screen widget funksiyası
  • Təhlükəsizlik, sui-istifadənin qarşısı və xidmətin işləməsi

4. Üçüncü tərəf xidmətlər

  • Firebase (Google): autentifikasiya, Firestore, Storage, Cloud Messaging, Analytics
  • Google Sign-In və Google Maps / Geolocation
  • Backend infrastruktur: API hostingu, MongoDB, Redis (keş), Socket.IO (canlı rezervasiya)
  • Telefon zəngi/e-poçt/naviqasiya cihazın sistem intent-ləri ilə açılır

Bu xidmətlərin öz məxfilik siyasətləri də tətbiq olunur.

5. Android icazələri

  • İnternet — tətbiqin server və xəritə ilə işləməsi
  • Dəqiq / təxmini məkan — yaxın klinikalar və xəritə
  • Bildirişlər — push bildirişlər
  • Foto/kamera (lazım olduqda) — heyvan şəkli əlavə etmək (qalereya və ya kamera)

6. Saxlanma və təhlükəsizlik

Məlumatlar xidmətin göstərilməsi üçün lazım olduğu müddət saxlanılır. Hesabı silmək funksiyası tətbiqdə mövcuddur; silmə sorğusu üçün eyni e-poçta da yaza bilərsiniz. Giriş tokenləri və əlaqə kanalları sənaye standartlarına uyğun qorunur; mütləq təhlükəsizlik vəd edilmir.

7. Uşaqlar

Baytarım 16 yaşdan kiçik uşaqlara yönəlməyib. Belə hesab aşkarlanarsa, silinməsi üçün bizimlə əlaqə saxlayın.

8. Hüquqlarınız

Məlumatlarınıza baxmaq, düzəliş və silmə tələb etmək hüququnuz var. Tətbiqdən çıxış və hesab silmə, həmçinin alekberovrufa@gmail.com vasitəsilə müraciət mümkündür.

9. Dəyişikliklər

Bu siyasət yenilənə bilər. Əhəmiyyətli dəyişikliklərdə tarix yenilənir və mümkün olduqda tətbiqdə bildiriş verilir.
